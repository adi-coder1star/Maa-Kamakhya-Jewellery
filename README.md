# Maa Kamakhya Jewellery — Website Source

This is the **Maa Kamakhya Jewellery (MKJ)** website project, adapted from the supplied `durga` starter repository. It is **not** the AARADHYA saree/clothing website.

## Business details
- **Business:** Maa Kamakhya Jewellery
- **Address:** NSCB Road, Lalpatti, Hojai, Assam
- **Phone / WhatsApp:** +91 98641 49113

## Features
- Mobile-friendly luxury black-and-gold jewellery showroom design
- Jewellery catalogue with categories and search
- Enquiry list (not a payment cart)
- WhatsApp product enquiries and general contact button
- Price-on-request wording
- Store location/contact section

## Run locally
Requirements: Node.js 22+ and npm.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. To check the static production build, run:

```bash
npm run build
```

## Before publishing
1. Confirm the phone number and exact address.
2. Replace any illustrative catalogue images with photos of actual stock approved by the shop.
3. Check the logo file in `public/maa-kamakhya-logo.png`; replace it with the official logo if needed.
4. Test all WhatsApp links on a phone.
5. Deploy the project using a host that supports Next.js static export.

## Important
This is an enquiry catalogue; it does not take online payments or guarantee product availability. Customers contact the shop on WhatsApp to confirm prices and stock.
